# Department of CSE (IoT and Cybersecurity Including Blockchain Technology)
### Guru Nanak Dev Engineering College, Bidar

An academic department portal built for the **Department of Computer Science and Engineering (IoT, Cybersecurity including Blockchain Technology)** at Guru Nanak Dev Engineering College, Bidar (NAAC A+ Accredited, VTU & AICTE Approved).

---

## 🌟 Key Features

- **Dark Singularity Canvas Atmosphere**: Custom WebGL/Canvas black-hole and cosmic accretion shader background with interactive orbital dynamics.
- **Continuous Tabs Component**: Built according to the [Watermelon UI](https://registry.watermelon.sh/r/continuous-tabs.json) specification with smooth spring physics, sliding indicator pill, and responsive panel switching.
- **Official Institutional Branding**: Embedded official emblem of Guru Nanak Dev Engineering College, Bidar, and the official Department of IoT & Cybersecurity / Cyber Samurai Association emblem.
- **Strict Academic Color Palette**:
  - Deep Teal / Navy — `#244855`
  - Coral Red — `#E64833`
  - Terracotta Brown — `#874F41`
  - Muted Sage — `#90AEAD`
  - Warm Cream — `#FBE9D0`
- **7 Comprehensive Pages**:
  1. `index.html` — Department Overview, Core Domains (IoT, Cyber Security, Blockchain), and HoD Welcome Message.
  2. `about.html` — Academic Vision, Core Mission (M1–M4), and Department Specialization.
  3. `faculty.html` — Full Faculty Directory Table and detailed faculty profile cards.
  4. `glimpse.html` — Milestone Events, Industry MoUs (MIBIZ Cyber Forensics, ISAC, Cyber DefenTech CoE), and EC-Council Training.
  5. `achievements.html` — 31 CEH Certified Students, VTU Examination Toppers, National Hackathons (Advaya 2.0), HBRP Research Publications, and IIT Hyderabad Academic Visit.
  6. `association.html` — Cyber Samurai Association, Logo Inauguration, and Technical Initiatives.
  7. `contact.html` — Department Contact, Head of Department Information, and Location details.

---

## 🚀 Running Locally

You can serve the static website using any local web server:

```bash
# Python 3
python -m http.server 3000

# Node.js (npx serve)
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
